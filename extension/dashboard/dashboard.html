Kréta API Korlátozás — Hiányozhatnak adatok

A hivatalos Kréta mobil gateway adatvédelmi szabályai miatt a TanuloAdatlap végpont nem minden személyes, pénzügyi vagy okmány adatot továbbít harmadik feleknek (például bankszámlaszám, adóazonosító, TAJ-szám). Ha bármely mezőnél "Nincs rögzítve" szerepel, kattints a "Profil Szerkesztése" gombra, ahol manuálisan kitöltheted, vagy a "Beolvasás Kréta lapról" gombbal 1 kattintással beemelheted őket a megnyitott hivatalos Kréta felületedről!
